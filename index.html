This photographic guide is intended to be a resource to help clinical investigators describe injection site reactions.

Examination tips

  • Use bright, neutral lighting; tangential light helps surface texture.
  • Measure longest and perpendicular axes with a ruler; photograph with scale when feasible.
  • Palpate for depth, warmth, fluctuance, and tenderness—especially when infection is a concern.

How to evaluate a lesion

Work through the same sequence for each encounter: morphology first, then distribution and size, then surface detail and patient-reported symptoms.

Primary morphology

Primary lesions describe the fundamental pattern before secondary change. Each card opens on the clinical photograph; use the button to reveal the matching Bolognia line-art crop. Figure notes from the workbook appear in the bordered panel under the morphologic definition—separate from the definition text. Diagram source: Plastic Surgery Key.

Secondary morphology

Secondary changes reflect evolution, trauma, infection, or chronicity superimposed on the primary lesion. Layout matches primary cards (photograph with button-toggle diagram, then definition and bordered figure notes). Diagram crops use the closest matching Bolognia primary-lesion illustration when a dedicated secondary figure is not provided.
