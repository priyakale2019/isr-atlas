How to describe an injection site reaction

Example description

vesicle within surrounding pink edematous plaque

Examination tips

  • Use bright, neutral lighting; tangential light helps surface texture.
  • Measure longest and perpendicular axes with a ruler; photograph with scale when feasible.
  • Palpate for depth, warmth, fluctuance, and tenderness—especially when infection is a concern.

How to evaluate a lesion

Work through the same sequence for each encounter: morphology first, then distribution and size, then surface detail and patient-reported symptoms.

Primary morphology

Primary lesions describe the fundamental pattern before secondary change. Each card opens on the clinical photograph; use the button to reveal the matching line drawing. Figure notes from the workbook appear in the bordered panel under the morphologic definition—separate from the definition text.

Secondary morphology
